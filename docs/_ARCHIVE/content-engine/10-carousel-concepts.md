## PRODUCTION WORKFLOW FOR ALL CAROUSELS

### Design Creation (Recommended Tool: Canva)

**Template Setup:**
1. Create master template with brand colors saved
2. Set up text styles (Cormorant Garamond + Inter presets)
3. Save padding guides (48px margins)
4. Export at 1080x1350px, PNG format

**Batch Production:**
- Sunday: Write all carousel copy for the week
- Monday: Design 2-3 carousels in one 90-minute session
- Use templates to speed up process
- Save designs in organized folders

### Quality Checklist Before Posting
- [ ] All text uses ONLY brand fonts (Cormorant Garamond OR Inter)
- [ ] All colors are from 5-color palette
- [ ] 48px minimum padding on all sides
- [ ] Mobile preview looks clean (test at 375px width)
- [ ] Typos checked (read backwards to catch errors)
- [ ] Your photos are high-resolution
- [ ] Slides flow logically
- [ ] CTA is clear and action-oriented
- [ ] Carousel fits grid aesthetic

### Time Estimates
- **First carousel:** 2 hours (learning curve)
- **Once templated:** 45 minutes per carousel
- **With batch workflow:** 2 hours for 3 carousels

## CAPTION WRITING TIPS FOR CAROUSELS

### Hook Formulas (First Line)
- Vulnerability: "I used to believe [myth]..."
- Pattern interrupt: "[Unexpected statement]."
- Direct benefit: "Here's how to [desired outcome]..."
- Story: "6 months ago I was [struggle]..."
- Question: "What would you do with [benefit]?"

### Body Structure
- Para 1: Hook (emotion or intrigue)
- Para 2-3: Context (your story/experience)
- Para 4: Value (what they'll learn)
- Para 5: Action (swipe through prompt)
- Para 6: Engagement question

### CTA Best Practices
- "Swipe through" or "Swipe →" (carousel-specific)
- "Save this for later" (drives saves = algorithm boost)
- "Comment [word]" (drives comments = engagement)
- "Share with someone who needs this" (drives shares = reach)
- "Follow for [specific benefit]" (drives follows)

### Length
- Carousels perform best with LONGER captions (200-300 words)
- People are already in "reading mode" from swiping slides
- Use line breaks generously (easier mobile reading)
- End with question to drive comments
