# Documentation Archive

Files under this directory are retained for history and evidence only.

They may contain:

- old routes and product names;
- expired launch dates and prices;
- retired agents, automations, or desktop tools;
- pre-cutover `/studio` architecture;
- draft copy that was never approved;
- implementation plans that were completed or superseded.

Archived material is not an instruction source. Start with `docs/README.md`, `CLAUDE.md`, and
`tasks/README.md`, then verify against live code.
