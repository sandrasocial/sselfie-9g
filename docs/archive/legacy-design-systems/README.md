# Legacy Design Systems

These files are retained for historical reference only. They are not current SSELFIE design
guidance. Future design work must follow `docs/SSELFIE_DESIGN_SYSTEM.md`.

This includes the superseded 2026-08-09 light/cool editorial system and the 2026-08-23 Bold
Editorial Studio reference. Sandra approved SSELFIE Noir Glass on 2026-08-27. Do not copy palettes,
softness rules, typography behavior, or layout defaults from files in this folder into current work.

Do not use these files to guide new email templates, landing pages, Maya UI, or app simplification
work unless Sandra explicitly asks to recover a specific historical detail.
