## Evidence rules

- Verify money from Stripe or qualifying `stripe_payments`.
- Verify behavior from the live UI, analytics, logs, and provider dashboards.
- Verify implementation from current code and production.
- Research, audits, strategy notes, and archives are historical evidence, not active instructions.
- Generated visual prompts, output folders, and existing inconsistent UI are not design authorities.
  For visual work, `SSELFIE_DESIGN_SYSTEM.md` wins.

Do not add implementation task lists, agent definitions, skill packages, generated audit output, or
cross-tool operating systems to this repository.
