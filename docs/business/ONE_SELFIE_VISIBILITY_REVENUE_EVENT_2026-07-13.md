## The decision

This event is a focused cash injection, not a permanent discount store.

The offer is the **One Selfie Visibility Bundle** for **$97 one-time**. It solves one problem: turning one real selfie into photos and content a woman can actually use to become more visible online.

The offer is deliberately not “all the courses.” The buyer sees one path:

1. Start with the selfie.
2. Make the photos.
3. Build the visible brand.
4. Keep creating with Maya.

Lifetime access:

- Selfie Starter Kit
- Full SSELFIE Presets Collection
- Editing Masterclass
- Branded by SSELFIE
- Prompt Vault

Fixed access:

- 30 days of SUITE
- 200 credits
- no subscription and no automatic renewal

The separately sold one-time tools total $260: Starter Kit $37, Presets $39, Masterclass $147, and Prompt Vault $37. The Masterclass contains both Editing Masterclass and Branded by SSELFIE.

Existing paid SUITE members should not buy this bundle. They already have the main ongoing value.

- 6,755 sendable email subscribers

- the strongest recent Instagram post had 77,791 views, 6,449 saves, 1,706 shares, and 905 comments

That evidence points to a clear, affordable result built from already useful products. It does not support dumping every old product into a large course package or pushing an unproven high price again.

Buyer home:

1. Open the Starter Kit and make the first selfie usable.
2. Open Presets and Prompt Vault to make more photos.
3. Open Editing Masterclass and Branded by SSELFIE to make the photos support the brand.
4. Open Maya and use the 30-day pass.

The annual SUITE option is a separate, transparent purchase after the buyer sees what she received. It uses the normal annual price. The closed founding offer is not reused.

Implementation invariants:

- The Account screen must distinguish a recurring SUITE membership, the fixed bundle pass, and
  lifetime bundle ownership. Only a real recurring membership shows renewal, monthly refill, or
  billing controls.
- Membership lifecycle writes are keyed to the exact Stripe subscription ID. They must never
  update every `subscriptions` row for a user, because bundle ownership, the fixed pass, and trials
  are separate rows.
- Production currently has a non-unique index on `subscriptions.stripe_subscription_id`. The
  launch-safe upsert uses an advisory lock, exact-ID update, and conditional insert. A future unique
  index requires a read-only duplicate audit and an attended migration; do not add it during an
  active revenue event.

If the event is closed, the page offers the $37 Starter Kit as the honest smaller next step.

## What is measured

Revenue truth comes from completed Stripe payments, not checkout starts.

Launch scorecard:

- page views by source
- primary CTA clicks
- checkout starts
- paid checkouts
- gross USD revenue
- refunds
- buyer-home opens
- each included product opened
- Maya opened
- first generation and first download during the 30-day pass
- annual SUITE upsell views, clicks, and completed EUR payments

Read the results in this order:

1. **Traffic:** Did enough qualified people see the offer?
2. **Page decision:** Did page visitors start checkout?
3. **Payment:** Did checkout starters complete?
4. **Activation:** Did buyers open the buyer home and make something?
5. **Continuation:** Did the 30-day pass produce repeat creation or a paid SUITE decision?

Do not change the price, page, or package while the event is running. That would make the result impossible to interpret.

## Monthly cash-injection operating rule

Run one attended 24–48 hour revenue event per month only when there is a clear audience problem and an existing product path that solves it.

Do not automatically discount the same bundle every month. That trains the audience to wait. Do not discount the same core products more than once per quarter.

Monthly cycle:

1. Review the previous event and current Activation Funnel.
2. Pick one measured customer problem.
3. Use one existing product or one safely fulfilled bundle.
4. Set one price, one fixed close, one keyword, and one checkout.
5. Prepare page, delivery, recovery, three email drafts, and social kit.
6. Run for 24–48 hours without changing it mid-event.
7. Review revenue the next day, activation after seven days, and downstream value after 30 days.
8. Keep, improve, or retire the event based on evidence.

Repeat this One Selfie event only if it produces:

- at least 10 buyers across the first event or a clear conversion signal from limited traffic
- less than 5% refunds
- no fulfillment failures
- at least 70% buyer-home opens
- meaningful first-week Maya use

## Ads gate

Do not send cold paid traffic to this first 48-hour event. Organic content and the existing email audience should prove the offer first.

Retargeting can be considered after the event has several verified organic purchases, the Pixel/Conversions API records landing, checkout, and purchase correctly, and fulfillment is clean. Start with people who already engaged with Sandra or visited the offer.

Cold ads should wait until all of these are true:

- at least 20 organic buyers across one or two controlled events
- at least 15% checkout-start-to-payment conversion
- less than 5% refunds
- zero unresolved fulfillment failures
- a maximum initial customer-acquisition target around $25–$30, until SUITE continuation proves higher lifetime value

Meta describes retargeting as reaching people who already know the business, and its Conversions API is designed to improve measurement between marketing data and Meta's systems. A new ad set also goes through a learning period, so frequent changes during a 48-hour event make the result less reliable.
