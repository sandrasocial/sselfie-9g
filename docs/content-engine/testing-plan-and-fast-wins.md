## WEEKLY TEST PLAN (30 Days)

**Testing Philosophy:** Test one variable at a time. Track data weekly. Adjust based on YOUR audience, not generic advice.

---

### WEEK 1 (Feb 16-22): BASELINE + HOOK TESTING

**What to Test:** Hook styles in first 3 seconds of reels and first line of captions

**Hypothesis:** Personal/vulnerable hooks will outperform educational hooks for your audience

**Test Variables:**
- **Test A:** Vulnerability hook ("I spent €1,200 on...")
- **Test B:** Educational hook ("5 secrets that changed...")
- **Test C:** Pattern interrupt ("Your brand photos don't need...")

**Content to Test:**
- Mon Feb 16: Carousel with educational hook
- Tue Feb 17: Personal story with vulnerability hook
- Wed Feb 18: Reel with pattern interrupt hook
- Thu Feb 19: Before/after with transformation hook

**Expected Signal:**
- Watch time >60% = good hook (reels)
- Click "...more" rate >40% = good hook (feed posts)
- First-hour engagement >5% = hook stopped scroll

**KPI Targets (Week 1 Baseline):**
- Reach: Track average
- Engagement Rate: Track average
- Save Rate: >3% (good), >5% (excellent)
- Profile Visits: Track average
- Follow Rate: Track average

**What to Track:**
| Day | Content Type | Hook Style | Reach | Engagement | Saves | Profile Visits | Notes |
|-----|--------------|------------|-------|------------|-------|----------------|-------|
| Mon | Carousel | Educational | | | | | |
| Tue | Personal | Vulnerability | | | | | |
| Wed | Reel | Pattern Interrupt | | | | | |
| Thu | Before/After | Transformation | | | | | |
| Fri | Stories | BTS | | | | | |

**End-of-Week Analysis:**
- Which hook style got highest saves? (Most valuable content)
- Which got most shares? (Most relatable)
- Which drove most profile visits? (Best scroll-stopper)
- Winner becomes primary hook style for Week 2

**Action for Week 2:** Double down on winning hook style

## FAST WINS IN FIRST 7 DAYS

**Quick actions to drive immediate results and momentum**

---

### DAY 1 (Sunday Before Launch): PREPARATION

**Time Required:** 2 hours

✅ **Write all Week 1 captions**
- Mon: Carousel caption (5 Selfie Secrets)
- Tue: Personal story (€12 beginning)
- Wed: Reel script (30-second brand photo)
- Thu: Before/after caption
- Fri: BTS caption
- Save in Notes app or Google Doc

✅ **Batch selfie session**
- 20 minutes by window
- 50+ photos minimum
- Variety: serious, smiling, looking away, looking direct
- Different angles: straight, 45° turn, profile

✅ **Set up content calendar**
- Use Later, Planoly, or native Instagram scheduler
- Input all Week 1 post times
- Prepare hashtag sets (create 3 variations, rotate)

✅ **Optimize bio**
- Clear value prop: "Teaching female entrepreneurs to build visibility with AI + selfies"
- Link to Brand Engine (use Linktree if multiple links needed)
- Add relevant keywords (personal branding, AI photos, visibility)

**Expected Result:** Entire Week 1 content ready to execute

### DAY 2 (Monday Feb 16): STRONG LAUNCH

**Time Required:** 3 hours

✅ **Create + post first carousel** (8 AM)
- "5 Selfie Secrets" carousel
- Use templates from carousel concepts doc
- Post at optimal time (8 AM recommended)
- Engage immediately: reply to comments within first hour

✅ **Stories hype**
- 3-5 stories throughout day
- Morning: "New carousel on feed - swipe for selfie secrets"
- Midday: Reshare carousel with "Save this!" sticker
- Evening: "What did you think of today's carousel?"

✅ **Engagement blitz** (2 hours)
- Comment on 30 accounts in your niche
