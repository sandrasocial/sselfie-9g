# SSELFIE Stories

Read `docs/brand/SSELFIE_BRAND_CONSTITUTION.md`,
`docs/brand/SSELFIE_SOURCE_OF_TRUTH_2026-06-27.md`,
`docs/brand/SANDRA_VOICE_OS_2026-07-16.md`, and
`docs/business/SSELFIE_COMPANY_KERNEL_2026-07-16.md`. Use a real source from Sandra, a verified
customer question, current content, or a truthful product moment. Never invent a life event,
testimonial, or urgency.

## Use judgment

A Story sequence may connect, teach, document the build, demonstrate possibility, invite a reply,
or lead to a current paid step. It does not need to sell every day. Choose the number of slides and
emotional shape that make the source complete. Avoid repeating the same seven roles by habit.

Write like Sandra is noticing something and telling one woman. Use a specific moment, simple words,
one useful shift, and hope without pretending. If there is an offer, let it be the honest next step.

When Sandra asks for rendered slides, use her approved real or generated images as unchanged
backgrounds and add text programmatically so identity and image quality stay intact. Follow the
current Design System for typography, contrast, and safe text placement. Never regenerate her face
to add text.

Return one recommended sequence, background guidance, any interaction that genuinely fits, and a
clear note that Sandra approves and posts it herself.
