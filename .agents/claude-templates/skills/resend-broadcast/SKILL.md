# SSELFIE Resend Broadcast

Sandra must approve all customer-facing copy and every send. This skill drafts and checks. It never sends, schedules, creates a broadcast, approves an Admin action, or mutates Resend.

## Read first

1. `docs/brand/SSELFIE_BRAND_CONSTITUTION.md`
2. `docs/brand/SSELFIE_SOURCE_OF_TRUTH_2026-06-27.md`
3. `docs/brand/SSELFIE_PURPOSE_MESSAGING_LOCK_2026-07-07.md`
4. `CLAUDE.md`
5. `docs/CODEX_CONTEXT.md`
6. `docs/AUTOMATION_ROSTER.md`
7. The active campaign contract and runbook, if one exists.

If an active campaign has fixed copy, timing, audience, or offer terms, it takes precedence over a generic email idea.

## Verify live facts every time

- Query Resend for the current audience/segment ID and subscribed count. Do not use an ID or count cached in a skill, memory, or old report.
- Query recent broadcast names, subjects, statuses, and send times before drafting. Do not rely on a stored history table.
- Read the current product definition, price, renewal, expiry, access, CTA route, and campaign close from current code and runbook.
- Use verified proof only. Do not invent customer language, quantities, revenue, scarcity, or performance.
- Keep all output in draft until Sandra approves it.

## Voice and ethics

- Simple everyday language that Sandra can say out loud.
- Short paragraphs. One idea. One clear action.
- Lead with a real moment, useful result, belief, or verified customer truth.
- No corporate wording, coach speak, fake urgency, income guarantees, or pressure involving children, divorce, fear, or financial insecurity.
- Use Sandra's own images only. If one is needed, mark `IMAGE NEEDED: Sandra to provide`.
- Follow the Constitution's message order. Freedom is the destination, not a forced headline.

## Deliverable

Provide:

1. Two subject options.
2. Preview text that adds to the subject.
3. Full plain-language body.
4. One CTA and verified destination.
5. The live audience or segment selected, with the verification time.
6. A suggested time with the reason, clearly marked as a recommendation.
7. A pre-send check for voice, offer truth, audience, links, suppression, proof, deadline, and Sandra approval.

Never claim a broadcast is ready to send until its current audience, links, product terms, suppression, and Resend draft state have been verified.
