# SSELFIE Product Marketing Context Router

This file contains no business facts by design. It is a routing file for marketing skills, not a source of truth.

Before any SSELFIE marketing, launch, page, email, ad, onboarding, pricing, retention, or offer work:

1. Read `docs/brand/SSELFIE_BRAND_CONSTITUTION.md` for brand law and ethical boundaries.
2. Read `CLAUDE.md` for current business state, active priorities, and current event precedence.
3. Read `docs/CODEX_CONTEXT.md` for current implementation constraints.
4. Read `docs/brand/SSELFIE_SOURCE_OF_TRUTH_2026-06-27.md` for detailed audience, founder story, expertise, and voice.
5. Read `docs/brand/SSELFIE_PURPOSE_MESSAGING_LOCK_2026-07-07.md` for audience temperature and offer routing.
6. Read `docs/funnel/NO_FAKE_AI_BRAND_PSYCHOLOGY_2026-06-10.md` before any AI-photo promise.
7. Read `docs/SSELFIE_DESIGN_SYSTEM.md` before recommending visible design changes.
8. Read the current named campaign, product, funnel, or event contract before making a recommendation.
9. Verify routes, products, prices, entitlements, and automation behavior in current code.
10. Use Stripe or `stripe_payments` for money truth and `analytics_events` for behavior truth.

Never rely on prices, audience counts, product lists, funnel states, routes, models, or performance numbers remembered from this routing file. Never duplicate the Brand Constitution here.

If an active attended campaign is named in `CLAUDE.md`, that event owns the day's selling message. Do not create a competing offer or unrelated sales draft.
