# SSELFIE Product Marketing Context Router

This file contains no business facts by design. It is a routing file for marketing skills, not a source of truth.

Before any SSELFIE marketing, launch, page, email, ad, onboarding, pricing, retention, or offer work:

1. Read `docs/brand/SSELFIE_BRAND_CONSTITUTION.md` for brand law and ethical boundaries.
2. Read `docs/business/SSELFIE_COMPANY_KERNEL_2026-07-16.md` for current offers, buyer channels,
   revenue engines, and AI-team roles.
3. Read `CLAUDE.md` for current business state and operational priorities.
4. Read `docs/CODEX_CONTEXT.md` for current implementation constraints.
5. Read `docs/brand/SSELFIE_SOURCE_OF_TRUTH_2026-06-27.md` for detailed audience, founder story, expertise, and voice.
6. Read `docs/brand/SSELFIE_PURPOSE_MESSAGING_LOCK_2026-07-07.md` for category execution.
7. Read `docs/funnel/NO_FAKE_AI_BRAND_PSYCHOLOGY_2026-06-10.md` before any AI-photo promise.
8. Read `docs/SSELFIE_DESIGN_SYSTEM.md` before recommending visible design changes.
9. Read the current named campaign, product, funnel, or event contract only after confirming the
   Company Kernel marks it active.
10. Verify routes, products, prices, entitlements, and automation behavior in current code.
11. Use Stripe or `stripe_payments` for money truth and `analytics_events` for behavior truth.

Never rely on prices, audience counts, product lists, funnel states, routes, models, or performance numbers remembered from this routing file. Never duplicate the Brand Constitution here.

Only a public campaign explicitly active in the Company Kernel may own the day's selling message.
Private high-value offers never enter unattended public content.
