================================================================================
KEY DESIGN DECISIONS
================================================================================

TEXT-ONLY ACTIONS
  - No icons (no lucide, no emoji)
  - All actions: "FAVOURITE", "ADD TO FEED", "EDIT", etc.
  - Cleaner, more premium look
  - Reduces visual clutter

MASONRY NOT GRID
  - Gallery: Editorial masonry (2 cols, mixed heights)
  - Like flipping through a magazine
  - Zero border-radius on cards (full-bleed)
  - Asymmetric, curated aesthetic

DARK MODE LUXURY
  - Pure black background (#0a0a0a)
  - High contrast with white text
  - Glassmorphic depth and layering
  - Premium like Apple, Figma, Notion

TAB NAVIGATION
  - Thin white underline on active tab
  - NOT filled buttons
  - Text-only uppercase labels
  - Uppercase, letter-spaced

NO ICONS EVER
  - Navigation icons: text labels
  - Actions: text labels
  - Status: text labels or badges
  - Only uses typography and glass effects

INSTAGRAM GRID SPECIFICATIONS (Feed Planner Hero)
================================================================================

Grid Layout
  - 3 columns x 3 rows = 9 cells
  - 2px gap between cells
  - Aspect ratio 1:1 (square cells)
  - Full width of 375px container
  - Equal-width columns

Cell Styling
  - No border-radius (square, full-bleed)
  - Images: object-fit cover

This is THE conversion moment. When all 9 posts generate, it looks like

MASONRY GRID SPECIFICATIONS (Gallery Photos)
================================================================================

Grid Layout

Height Variations

  - Feels curated, not algorithmic

Hover Behavior
  - Overlay: Dark gradient overlay
  - Text actions: "FAVOURITE", "ADD TO FEED"
  - Opacity change on hover
  - Smooth 0.3s transitions
