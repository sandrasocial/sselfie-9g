DESIGN SYSTEM
================================================================================

COLORS (SSELFIE Official 5-Color Palette):
  Obsidian (#0a0a0a)    — Primary background, creates luxury dark canvas
  Porcelain (#ffffff)   — Primary text, maximum contrast
  Pearl (#f5f5f5)       — Secondary text, subtle highlights
  Smoke (#666666)       — Captions, metadata, de-emphasized
  Whisper (#e5e5e5)     — Subtle dividers, ultra-light accents

TYPOGRAPHY:
  Display/Headers:      Cormorant Garamond (weight 200-300)
  Body:                 Inter (weight 300, 16px minimum)
  Labels:               Inter (weight 500, 10-12px, uppercase, 0.5em tracking)

SPACING:
  Desktop:              80px side padding (5vw clamp)
  Mobile:               24px side padding (5vw clamp)
  Sections:             60-160px vertical padding (responsive clamps)
  Gap between elements: Clamp functions for fluid spacing

IMAGERY:
  All placeholders use CSS linear-gradient with no border-radius
  Portrait style:       linear-gradient(160deg, #2a2a2a 0%, #1a1a1a 40%, #333)
  Landscape style:      linear-gradient(135deg, #1f1f1f 0%, #2d2d2d 100%)
  Can be replaced with real images by updating background property

ANIMATIONS:
  Fade-in-up:           translateY(30px) → 0, opacity 0 → 1 over 1s
  Scale-in:             scale(0.95) → 1, opacity 0 → 1 over 1s
  Hover states:         All CTAs invert (white bg, black text) on hover
  Scroll triggers:      Intersection Observer for on-scroll reveals

================================================================================
TROUBLESHOOTING
================================================================================

COMMON ISSUES:

Checkout doesn't work?
  → Check /api/academy/checkout endpoint is live
  → Verify product IDs match database
  → Check browser console for errors
  → Verify user is authenticated (should redirect to login if not)

Images not showing?
  → Currently using CSS gradients intentionally (no broken images)
  → To add real images: replace background property
  → Ensure image paths are correct relative to serving location

Mobile layout broken?
  → Check viewport meta tag is present
  → Resize browser window or use Chrome DevTools
  → Verify no element exceeds 100vw (overflow: hidden on body)

Animations not working?
  → Browser supports CSS animations (all modern ones do)
  → Check JavaScript enabled
  → Scroll through page to trigger Intersection Observer
  → Check console for errors

Stripe redirects to login?
  → This is expected! User not authenticated
  → After login, they return to Academy page
  → This matches app behavior
