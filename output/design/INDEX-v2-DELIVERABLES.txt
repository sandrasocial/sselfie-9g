================================================================================
DESIGN SYSTEM HIGHLIGHTS
================================================================================

COLOR PALETTE (Mandatory)
────────────────────────────────────────────────────────────────────────────
Obsidian:        #0a0a0a   ← All backgrounds
Porcelain:       #ffffff   ← Primary text
Pearl:           #f5f5f5   ← Secondary text
Smoke:           #666666   ← Captions, disabled
Whisper:         #e5e5e5   ← Borders
Glass Surface:   rgba(255,255,255,0.04)   + blur(20px)
Glass Border:    1px solid rgba(255,255,255,0.08)
Glass Elevated:  rgba(255,255,255,0.07)


TYPOGRAPHY (Mandatory)
────────────────────────────────────────────────────────────────────────────
Headers:       Cormorant Garamond, 200-300 weight, UPPERCASE, -0.01em tracking
Body:          Inter, 300 weight, 16px minimum, 1.8 line-height
Labels:        Inter, 500 weight, 10-12px, UPPERCASE, 0.5em tracking
Fonts:         Google Fonts CDN (no external dependencies)


DESIGN PRINCIPLES (7 Core Rules)
────────────────────────────────────────────────────────────────────────────
1. Dark backgrounds ALWAYS (Obsidian #0a0a0a)
2. Glass panels for all cards (20px blur backdrop-filter)
3. NO ICONS (avoid Lucide, emoji; use Unicode sparingly)
4. Images are HERO (Instagram previews are centerpiece)
5. Asymmetric/editorial layout (not strict grid)
6. Mobile-first (375px minimum breakpoint)
7. Thin borders ONLY (1px glass borders)


================================================================================
MAYA FEATURE ARCHITECTURE (6 TABS)
================================================================================

TAB 1: CLASSIC
  → Chat with Maya, quick prompts, single image generation
  → Generate photo → Instagram Photo Card
  → Photoshoot button → 6-9 carousel → Instagram Carousel Card
  → Credits: 2 per image, 9 per photoshoot

TAB 2: PRO
  → Upload reference images
  → Create concept cards with editable prompts
  → 2-column grid (mobile: 1 column)
  → Each card: image, title, category, prompt editor, generate button

TAB 3: VIDEOS
  → Image gallery (portrait 9:16 format)
  → Click to animate → motion video
  → Result: Instagram Reel preview
  → Credits: 3 per video

TAB 4: PROMPTS
  → Curated editorial prompt library
  → Click prompt → generates image directly
  → Future: category filters, fashion-forward styles

TAB 5: TRAINING (Membership Only)
  → Upload 10-15 selfies
  → Train custom Flux model
  → Status card with training progress

TAB 6: FEED (Locked)
  → Show as disabled/coming soon
  → Future social feed integration
